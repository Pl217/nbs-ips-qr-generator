# Генератор NBS IPS QR кôда

Апликација за генерисање NBS IPS QR кôдова за плаћања у Републици Србији. Апликација омогућава креирање QR кôдова који су компатибилни са банкарским апликацијама и сервисима који користе IPS (Instant Payment System) стандард.

## Карактеристике

- 🔒 **Валидација података** - Аутоматска провера исправности броја рачуна по ISO 7064 стандарду
- 🏦 **Препознавање банака** - Аутоматско препознавање банке на основу броја рачуна, са визуелном потврдом (✓)
- 💰 **Форматирање износа** - Аутоматско форматирање износа са сепараторима хиљада и обавезним децималним делом
- 🌓 **Светла/тамна тема** - Подршка за светли и тамни режим
- 🔤 **Подршка за оба писма** - Ћирилица и латиница у интерфејсу
- 💾 **Чување кôдова** - Могућност чувања често коришћених кôдова у локалном складишту
- 📱 **Респонзиван дизајн** - Прилагођен за мобилне уређаје и десктоп
- ✅ **Валидација по ISO/IEC 7064** - Позив на број одобрења подржава алфанумеричке карактере
- 🚀 **PWA подршка** - Може се инсталирати као апликација на мобилним уређајима и десктопу
- 📴 **Офлајн рад** - Ради и без интернет конекције након инсталације

## Deployment на GitHub Pages

Овај пројекат је спреман за deployment на GitHub Pages. Подешен је аутоматски deployment.

### Аутоматски deployment

- GitHub Actions ће аутоматски покренути build и deploy при сваком push-у
- Апликација ће бити доступна на `https://pl217.github.io/nbs-ips-qr-generator`

### Важне напомене за GitHub Pages

- Сви потребни фајлови се копирају у root приликом build-а
- `.nojekyll` фајл онемогућава Jekyll processing
- PWA функционалност ради на HTTPS (GitHub Pages користи HTTPS)
- Service Worker захтева HTTPS за правилан рад

## Покретање

### Production Build

За креирање финалне верзије апликације:

```bash
npm run build
```

Ова команда:

1. Компајлира TypeScript (`npm run compile`)
2. Bundle-ује све CSS и JS фајлове у један `index.html` (`npm run bundle`)

Финални фајл `index.html` у root директоријуму садржи комплетну апликацију и може се отворити директно у browser-у.

### Clean

За уклањање компајлираних фајлова:

```bash
npm run clean
```

### Reinstall

За поновну инсталацију зависности:

```bash
npm run reinstall
```

## Коришћење

1. **Отворите `index.html`** у браузеру након build-а
2. **Попуните обавезна поља**:
   - Број рачуна примаоца (18 цифара)
   - Назив примаоца плаћања
   - Износ (аутоматски се додаје ,00 за децимале)
   - Шифра плаћања
3. **Опционо попуните**:
   - Подаци о платиоцу
   - Сврха плаћања
   - Позив на број одобрења (подржава A-Z и 0-9)
4. Кликните **„Генериши Кôд”**
5. QR кôд ће бити приказан и спреман за скенирање

### Чување кôдова

- Кликните на **„Сачувај”** дугме да сачувате тренутне податке
- Сачувани кôдови се чувају у браузеру (Local Storage)
- Приступите сачуваним кôдовима преко иконице менија (☰)
- Кликните на сачувани кôд да га учитате

### Промена теме и језика

- **Тема**: Кликните на иконицу сунца/месеца у заглављу
- **Језик**: Кликните на дугме LAT/ЋИР за промену писма

### Инсталација као PWA

Апликација се може инсталирати на вашем уређају:

**На мобилним уређајима (Android/iOS):**

1. Отворите апликацију у браузеру (Chrome, Safari, итд.)
2. Кликните на „Додај на почетни екран” или „Install app”
3. Апликација ће бити доступна као засебна икона

**На десктопу (Chrome, Edge):**

1. Отворите апликацију у браузеру
2. Кликните на иконицу за инсталацију у адресној линији
3. Апликација ће бити инсталирана и покретаће се у засебном прозору

**Офлајн рад:**

- Након прве посете, апликација ће радити и без интернета
- Сви генерисани QR кôдови се креирају локално на вашем уређају

## Валидација

Апликација врши следеће валидације:

### Број рачуна

- Мора садржати тачно 18 цифара
- Банка мора бити регистрована у систему (прве три цифре које представљају идентификатор банке)
- Контролни број мора проћи ISO 7064 Mod 97 проверу

### Износ

- Обавезан децимални део (аутоматски додаје ,00)
- Максимум 2 децимале
- Аутоматско форматирање са тачкама за хиљаде

### Позив на број одобрења

- Подржава алфанумеричке карактере (0-9, A-Z)
- Валидација по ISO/IEC 7064 Mod 97 стандарду
- Прве 2 цифре су контролни број

### Имена (Назив примаоца, Подаци о платиоцу)

- Дозвољена су слова **САМО** српске латинице
- Валидна латиница: abcčćdđefghijklmnoprsštuvzž
- Ћирилица није дозвољена :(
- Дозвољени размаци између речи
- Дозвољени су бројеви, тачка и зарез
- Не дозвољава само размаке без слова

## Структура IPS QR кôда

Генерисани QR кôд садржи:

```
K:PR|V:01|C:1|R:<račun>|N:<naziv>|I:RSD<iznos>|SF:<šifra>|P:<platilac>|S:<svrha>|RO:<poziv>
```

Где су:

- **K** - Константа „PR” (payment request)
- **V** - Верзија „01”
- **C** - Кодирање „1”
- **R** - Број рачуна (18 цифара без цртица)
- **N** - Назив примаоца
- **I** - Износ у формату RSD<iznos> (нпр. RSD1.234,56)
- **SF** - Шифра плаћања
- **P** - Подаци о платиоцу (опционо)
- **S** - Сврха плаћања (опционо)
- **RO** - Позив на број одобрења (опционо)
